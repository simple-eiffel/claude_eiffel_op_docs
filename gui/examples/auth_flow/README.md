# Authentication Flow Example

Complete login workflow with error recovery and loading states.

## Pattern: Authentication with Error Handling

This example demonstrates:
- Initial login form state
- Loading spinner during authentication
- Error message display on failure
- Recovery flow (retry or cancel)
- Success state with automatic window closure

## What eiffel-gui-ux Generates

The `auth_flow.json` spec shows what an AI-assisted GUI UX design generates from a specification:

1. **Layout**: Vertical form with username, password, error panel, spinner
2. **Widgets**: Text fields, password field, progress bar, buttons
3. **State Machine**: 4 states (logged_out, authenticating, authenticated, auth_error) with transitions
4. **Guards**: Validation rules (username_not_empty, password_not_empty)
5. **Actions**: Entry/exit actions for state changes

## Implementation in simple_vision

### Create State Machine

```eiffel
create_state_machine (sv: SV_QUICK)
  do
    machine := sv.state_machine ("auth_flow")

    machine.state ("logged_out").described_as ("Form visible").do_nothing
    machine.state ("authenticating")
      .described_as ("Loading...")
      .on_entry (agent show_spinner)
      .on_exit (agent hide_spinner)
    machine.state ("authenticated").described_as ("Success")
      .on_entry (agent close_window)
    machine.state ("auth_error").described_as ("Show error")
      .on_entry (agent show_error)

    machine.on ("login")
      .from_state ("logged_out").to ("authenticating").apply
      .do_action (agent authenticate)
    machine.on ("success")
      .from_state ("authenticating").to ("authenticated").apply.do_nothing
    machine.on ("failure")
      .from_state ("authenticating").to ("auth_error").apply.do_nothing
    machine.on ("retry")
      .from_state ("auth_error").to ("logged_out").apply.do_nothing

    machine.set_initial ("logged_out")
  end
```

### Create Widgets

```eiffel
create_widgets (sv: SV_QUICK)
  do
    main_window := sv.window ("Login").sized (400, 320)
      .child (
        sv.column.padding (20).spacing (15)
          .child (sv.text ("Sign In").font_size (24).font_weight ("bold"))
          .child (create_username_field (sv))
          .child (create_password_field (sv))
          .child (create_error_panel (sv))
          .child (create_spinner (sv))
          .child (create_buttons (sv)))
  end
```

### Handle Events

```eiffel
handle_login_click
  do
    if not username_field.is_empty and not password_field.is_empty then
      machine.trigger ("login")
    end
  end

authenticate
  do
    -- Call API or check database
    if api.authenticate (username_field.value, password_field.value) then
      machine.trigger ("success")
    else
      machine.trigger ("failure")
    end
  end

show_spinner
  do
    spinner.show
    login_button.disable
  end

show_error
  do
    error_panel.show
  end

close_window
  do
    main_window.close
  end
```

## Key Patterns Demonstrated

1. **Conditional Visibility**: Error panel visible only in error state
2. **Button Enabling**: Login button disabled until fields filled and not loading
3. **Loading Indicator**: Spinner visible during async operation
4. **State-Driven UI**: State machine controls all visual updates
5. **Error Recovery**: User can retry or cancel from error state
6. **Entry/Exit Actions**: Automatic cleanup on state transitions
