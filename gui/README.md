# Simple Eiffel GUI Reference Guide

Comprehensive reference documentation for the **Simple Eiffel GUI ecosystem**, consolidating simple_vision, simple_spec_viz, and simple_graphviz into a unified guide.

## Overview

This reference covers:
- **[simple_vision](https://github.com/simple-eiffel/simple_vision)** - Modern GUI toolkit (Phase 7, 40+ widgets)
- **[simple_spec_viz](https://github.com/simple-eiffel/simple_spec_viz)** - Specification visualizer with JSON support
- **[simple_graphviz](https://github.com/simple-eiffel/simple_graphviz)** - State diagram visualization

## How simple_spec_viz Fits In

The complete AI-assisted workflow:

```
Developer Idea (shallow or deep)
         ↓
   eiffel-research (7-step investigation)
         ↓
   eiffel-spec (specification from research)
         ↓
   eiffel-gui-ux (generates JSON from specs for Windows GUI, TUI, WebView2)
         ↓
   JSON Specification (AI-generated)
         ↓
   simple_spec_viz (visualize JSON → SVG diagrams)
         ↓
   State Diagrams + Screen Mockups (SVG)
         ↓
   Dev + AI Review (visual feedback on AI-generated spec)
         ↓
   simple_vision (developer implements in Eiffel)
```

**simple_spec_viz provides visual feedback on JSON specs** before implementing in simple_vision, allowing dev+AI to catch design issues early.

## Features Overview

### Widgets (40+)

**Basic:** Text, Button, Checkbox, Radio, Dropdown, List, Slider, Progress, Spin Box

**Input:** Text Field, Password, Email, Phone, Date, Date (ISO), Credit Card, SSN, ZIP Code, IP Address, Time

**Containers:** Row, Column, Grid, Tabs, Card, Scroll Area, Stack, Splitter

**Data:** Data Grid, Decimal, Currency, Tree

**Application:** Menu Bar, Menu, Menu Item, Toolbar, Toolbar Button, Status Bar

**Dialogs:** File Open, File Save, Message Box (Info/Warning/Error/Question), Color Picker, Font Picker

**Layout Helpers:** Spacer, Separator, Divider

**Graphics:** Canvas (Cairo), Waveform

### State Machines

- Declarative UI state management
- States, transitions, guards, entry/exit actions
- Event-driven architecture
- JSON specification support
- Visual state diagram generation (via simple_graphviz)

### Forms & Validation

- Validation rule types: required, min/max length, range, email, pattern
- Field-level and form-level validation
- Real-time vs on-submit validation
- Grouped validation for complex forms

### Theming

- Dark mode support
- Color scheme selection (blue, green, purple)
- UI scaling (zoom in/out)
- Custom color definitions

## Design Principles

1. **Fluent API** - Chainable widget construction for readability
2. **Type Safety** - Eiffel contracts prevent misuse
3. **State Machines** - Declarative UI state prevents bugs
4. **Contracts First** - Preconditions catch errors early
5. **Void Safety** - All code is `void_safe` - no null exceptions
