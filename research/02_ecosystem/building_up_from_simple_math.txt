  How simple_probability & simple_montecarlo Fit In

  simple_probability:
  - Foundational: provides distributions (Normal, Uniform, Exponential, etc.)
  - Used by: simple_montecarlo, simple_statistics, simple_physics
  - Independent: doesn't depend on calculus or linalg

  simple_montecarlo:
  - Depends on: simple_probability (for sampling), simple_random
  - Provides: stochastic integration, particle methods, ensemble sampling
  - Compatible with simple_calculus: both solve ∫f(x)dx
  -- User chooses method:
  integral_deterministic := calc.integrate (agent f, 0.0, 1.0)
  integral_stochastic := montecarlo.integrate (agent f, 0.0, 1.0, n_samples)
  -- Same answer, different approach

  simple_physics Orchestrates All Layers

  -- Deterministic Newton-Raphson (uses calculus + linalg)
  solution := physics.newton_raphson (
      agent nonlinear_f,
      initial_guess
  )
  -- Internally: Jacobian via calculus, LU solve via linalg

  -- Stochastic particle simulation (uses probability + montecarlo)
  particles := physics.simulate_brownian_motion (
      initial_positions,
      temperature,
      time_steps
  )
  -- Internally: samples from probability distributions, MC integration

  -- Hybrid uncertainty quantification (uses both)
  ensemble := physics.ensemble_simulation (
      deterministic_model,    -- uses calculus + linalg
      parameter_distribution  -- uses probability + montecarlo
  )
